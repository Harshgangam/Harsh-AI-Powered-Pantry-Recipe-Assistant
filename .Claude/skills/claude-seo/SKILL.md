# Claude SEO & GEO Optimization Engine

An exhaustive search engine optimization and AI discovery framework containing 25+ automated sub-skills and 18 specialist analysis roles. It audits and optimizes websites for Google, Bing, and Generative Engine Optimization (Perplexity, ChatGPT Search, Google AI Overviews).

## The 5 Audit Pillars

### 1. Technical SEO & Architecture
- Crawlability, `robots.txt` configuration, XML sitemap validation, canonical tags (`<link rel="canonical">`).
- Status codes, redirect chains (301/302), and orphan page detection.

### 2. Generative Engine Optimization (GEO)
- Formatting content for AI summarization engines: Clear factual definitions, structured HTML tables, explicit FAQ sections, and direct authoritative answers.
- Information Gain Score: Ensuring original research, data tables, and distinct perspectives.

### 3. Schema.org & Structured Data (JSON-LD)
- Implementation of rich structured data schemas: `Article`, `Product`, `SoftwareApplication`, `FAQPage`, `BreadcrumbList`, `Organization`, `HowTo`.

### 4. E-E-A-T & Content Quality
- Experience, Expertise, Authoritativeness, and Trustworthiness signals: Author bios, citation links, review timestamps, and editorial policies.

### 5. Performance & Core Web Vitals
- Largest Contentful Paint (LCP <= 2.5s), Interaction to Next Paint (INP <= 200ms), Cumulative Layout Shift (CLS <= 0.1).

## Commands & Workflows

- `/seo audit <url-or-dir>`: Run full technical, content, and structured data audit.
- `/seo schema generate <type>`: Generate validated JSON-LD schema markup.
- `/seo geo-optimize <page>`: Restructure content to maximize inclusion in AI search summaries and answers.
- `/seo vitals <url>`: Audit Core Web Vitals and identify performance bottlenecks.
